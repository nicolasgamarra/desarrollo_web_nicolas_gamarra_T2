# Tarea 2 – Plataforma de Actividades 

Repositorio para la Tarea 2 del curso **CC5002 - Desarrollo de Aplicaciones Web**, semestre Otoño 2025.

Descripcion

Este sistema permite registrar, listar y visualizar actividades comunitarias asociadas a distintas regiones y comunas de Chile. Los usuarios pueden:
- Agregar actividades con sector, temas, contactos y fotos.
- Visualizar las últimas actividades en portada.
- Consultar un listado paginado y ver el detalle de cada actividad.

Tecnologias
- Python 3.11+, Flask, MySQL (vía PyMySQL), SQLAlchemy, HTML, CSS y JavaScript
